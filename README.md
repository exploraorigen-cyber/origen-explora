# ORIGEN

## Proyecto Web

Sitio web oficial para **ORIGEN**, un proyecto enfocado en experiencias de aventura, exploración y actividades al aire libre.

---

## Concepto

> **VUELVE A DONDE TODO EMPIEZA.**

ORIGEN busca conectar a las personas con:

* Naturaleza
* Reto
* Aprendizaje
* Conexión

La propuesta no consiste únicamente en vender actividades o tours.

La experiencia busca que las personas:

* Exploren.
* Aprendan habilidades.
* Enfrenten retos personales.
* Salgan de la rutina.
* Conecten con otras personas y con el entorno.

> **NO VENIMOS SOLAMENTE A CONOCER LUGARES.
> VENIMOS A VIVIRLOS.**

---

# Objetivo del sitio web

El sitio web tendrá tres objetivos principales:

## 1. Inspirar

Generar interés y deseo de explorar y vivir experiencias de aventura.

## 2. Informar

Permitir que el usuario conozca claramente:

* Las experiencias disponibles.
* Los niveles de dificultad.
* Qué aprenderá.
* Qué incluye cada actividad.
* Qué necesita llevar.
* Las próximas salidas.
* Los requisitos y medidas de seguridad.

## 3. Convertir

Guiar al usuario a través del proceso:

```text
INTERÉS
   ↓
INFORMACIÓN
   ↓
CONFIANZA
   ↓
RESERVA
   ↓
PAGO
```

# Forma de trabajo

## Analizar antes de cambiar

Antes de realizar cambios importantes se deben revisar los documentos, recursos y estructura existente.

## Un cambio a la vez

Los cambios se realizarán de manera progresiva y se validarán antes de continuar.

## No reinventar

Antes de reemplazar una estructura, archivo o funcionalidad existente, primero se debe analizar.

## Validar

Después de cada cambio importante:

1. Probar.
2. Revisar el resultado.
3. Corregir únicamente lo necesario.
4. Continuar.
